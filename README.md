
# ✦ FitTrack – Fitness & Wellness Dashboard

FitTrack is a responsive fitness and wellness dashboard designed to help users understand their bodies, monitor their daily goals, and build healthier habits.

Built with **HTML, CSS, and JavaScript**, the project provides simple and interactive tools for tracking important fitness metrics.

## 🌟 Features

### ⚖️ BMI Calculator
- Calculate Body Mass Index using height and weight.
- Display BMI values and corresponding categories.
- Get a simple interpretation of your result.

### 🔥 Daily Calorie Estimator
- Estimate daily calorie requirements.
- Calculate energy needs based on age, sex, height, and weight.
- Choose between three fitness goals:
  - Lose weight
  - Maintain weight
  - Gain weight
- Adjust estimates according to activity level.

### 💧 Water Intake Tracker
- Calculate an approximate daily water goal based on body weight.
- Track daily water consumption.
- Add 250 ml, 500 ml, or 750 ml of water.
- Remove water intake or reset daily progress.
- Save daily progress using Local Storage.

### 📊 Personal Dashboard
- View your BMI result.
- See estimated daily maintenance calories.
- Monitor daily water intake progress.

### 📱 Responsive Design
- Clean and modern user interface.
- Responsive layouts for different screen sizes.
- Easy navigation between sections.

## 🛠️ Technologies Used

## 🧮 Calculations

FitTrack uses the following methods:

- **BMI:** Weight (kg) / Height (m)²
- **Calorie Estimation:** Mifflin-St Jeor equation combined with an activity multiplier.
- **Water Goal:** An approximate target of 35 ml per kg of body weight.

**Note:** These calculations provide general estimates and are not medical advice. Individual nutritional and hydration needs may vary.
